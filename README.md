# Тестовое задание на должность Фронтенд разработчик React (GREEN-API)

## Описание
Веб-приложение для обмена текстовыми сообщениями через API GREEN-API (мессенджер MAX/Telegram/WhatsApp).

## Функционал
- Авторизация по `idInstance` и `apiTokenInstance`.
- Валидация входных данных (ID инстанса и токена).
- Создание чатов по номеру телефона (с валидацией и автоформатированием).
- Отправка и получение текстовых сообщений (Long Polling).
- Отображение статусов сообщений (отправлено, доставлено, прочитано).
- Счетчик непрочитанных сообщений.
- Удаление чатов.
- Переключение светлой/темной темы (сохраняется в localStorage).
- Адаптивная верстка (мобильная версия с кнопкой "Назад").
- Всплывающие уведомления (тостеры) для обработки ошибок.

## Технологии
- React (Vite)
- @mdi/react, @mdi/js (иконки)
- CSS3 (Переменные для тем)

## Инструкция по локальному запуску
1. Установите зависимости: `npm install`
2. Запустите проект: `npm run dev`
3. Откройте в браузере: `http://localhost:5173`

## Важное примечание по тестированию
Для получения статусов сообщений и входящих сообщений убедитесь, что в настройках вашего инстанса в личном кабинете GREEN-API:
1. Очищено поле `Webhook URL`.
2. Включены уведомления `incomingWebhook` и `outgoingWebhook`.
